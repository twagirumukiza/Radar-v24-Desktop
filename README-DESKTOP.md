# Radar V24 Desktop
Projet Tauri prêt à compiler sur Windows, Linux et macOS.

GitHub : déposer tout le contenu du dossier dans le dépôt, puis Actions > Build Radar Desktop > Run workflow.
Les installateurs générés sont disponibles dans les Artifacts du workflow.

Cibles : Windows .exe/.msi ; Linux .deb/.AppImage ; macOS .app/.dmg selon les bundlers disponibles.
